# Utilería JS - Herramientas de Validación Frontend

**Autor:** [Tu Nombre]  
**Problema que resuelve:** Esta librería proporciona validaciones esenciales del lado del cliente sin depender de frameworks pesados. Resuelve problemas comunes como verificar la fortaleza de contraseñas, validar direcciones de correo, calcular dinámicamente edades a partir de fechas de nacimiento y limpiar entradas de texto mal formateadas por los usuarios.

## Instalación
Para utilizar esta librería en cualquier proyecto web, simplemente copia el archivo `utileria.js` en tu directorio de scripts e inclúyelo en tu archivo HTML justo antes de cerrar la etiqueta `</body>`:

```html
<script src="js/utileria.js"></script>
